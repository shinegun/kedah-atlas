# Panduan gaya Bahasa Melayu — Atlas Kedah

Bahasa Melayu (BM) ialah bahasa lalai laman ini. Tulis dalam **BM Malaysia baku**, bukan Bahasa Indonesia, dan bukan terjemahan harfiah daripada Bahasa Inggeris. Semak dengan `uv run python pipeline/check_bm.py` sebelum menerbitkan.

## 1. Sumber rujukan (mengikut keutamaan)

1. **PRPM / Dewan Bahasa dan Pustaka** — <https://prpm.dbp.gov.my> (Kamus Dewan, Daftar Istilah) untuk ejaan, imbuhan dan istilah.
2. **Istilah rasmi DOSM** — gunakan nama penerbitan dan istilah statistik tepat seperti dalam terbitan BM DOSM (lihat glosari di bawah). Jika DOSM dan kamus berbeza untuk nama kategori statistik, ikut DOSM.
3. **Korpus rujukan gaya**: siaran media DOSM, berita Bernama, laporan Bank Negara Malaysia — nada formal tetapi mudah difahami.

## 2. Nada

- Formal-mesra: seperti siaran media DOSM, bukan surat pekeliling. Ayat pendek. Suara aktif.
- Tulis untuk penduduk Kedah biasa. Terangkan istilah teknikal sekali (cth. *analisis shift-share*), kemudian guna dengan konsisten.
- Jangan terjemah struktur ayat Inggeris perkataan demi perkataan. Tulis semula maksudnya.

## 4. Tatabahasa yang kerap salah

- **dari / daripada**: *dari* untuk tempat, masa dan arah (*berpindah keluar dari Baling*, *dari 2015 hingga 2019*). *Daripada* untuk orang, institusi, sumber, perbandingan dan perkara abstrak (*data daripada DOSM*, *lebih tinggi daripada*, *jalan keluar daripada kemiskinan*).
- **di mana**: hanya untuk soalan. Jangan guna sebagai kata hubung relatif (❌ *daerah di mana kekurangannya…* → ✅ *daerah yang ketinggalan*).
- **adalah / ialah**: *ialah* sebelum kata nama (*Anggaran ini ialah model kami*); *adalah* sebelum kata sifat atau frasa sendi (*Data ini adalah terbuka*). Lebih baik elakkan kedua-duanya jika ayat boleh berdiri tanpanya.
- **ia / dia**: jangan guna *ia*. Jangan juga gantikan dengan *dia* bagi benda atau tempat (terlalu lisan). Namakan subjek atau susun semula ayat (❌ *ia menjadi punca…* → ✅ *kaitan inilah yang mencetuskan…*). *Dia* hanya untuk orang.
- **kenapa / mengapa**: guna *kenapa* — lebih mesra pembaca untuk laman ini.
- **vs** → *berbanding*.
- **Nombor kecil dalam ayat**: tulis satu hingga sepuluh dengan perkataan (*satu daripada tujuh isi rumah*); angka statistik kekal sebagai digit.
- **&**: boleh dalam label carta yang sempit, tetapi guna *dan* dalam ayat dan nama rasmi (*Survei Pendapatan dan Perbelanjaan Isi Rumah*).
- **Kali ganda**: *2.2 kali purata Kedah*, bukan *2.2× purata Kedah* dalam ayat penuh (simbol × boleh dalam label carta).
